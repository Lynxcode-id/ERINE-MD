## 🌙&nbsp; Tentang Bot

**ERINE-AI PROJECT** adalah bot WhatsApp multi-device dengan sistem plugin yang fleksibel dan stabil.
Bot ini dibuat untuk hiburan, utilitas, downloader, dan otomatisasi grup maupun chat pribadi.

<br>

Cocok digunakan untuk:

🔸&nbsp; Download media
🔸&nbsp; Game & fun command
🔸&nbsp; Manajemen grup
🔸&nbsp; AI tools
🔸&nbsp; Sticker maker
🔥&nbsp; Berjualan
⚡&nbsp; Open jasa sewa bot
😎&nbsp; Open jasa jadibot
🌟&nbsp; Push kontak
🥸&nbsp; Jpm jasa share gtulah
✨&nbsp; Dan masih banyak lagi chuy..

## ✨&nbsp; Fitur Utama

Bot ini dilengkapi dengan berbagai fitur yang terorganisir dalam plugin.

<br>

| Kategori | Deskripsi |
| :--- | :--- |
| 🤖&nbsp; **AI Tools** | Chat AI, prompt tools, generator teks. |
| 📥&nbsp; **Downloader** | TikTok, YouTube, Instagram, Facebook, dll. |
| 🎮&nbsp; **Hiburan** | Truth, Dare, Tebak Gambar, RPG, dan game lainnya. |
| 👥&nbsp; **Manajemen Grup** | Welcome, Anti Link, Kick, Hidetag, dll. |
| 🛠️&nbsp; **Utilitas** | QR Generator, Convert Tools, Media Tools. |
| 🖼️&nbsp; **Sticker** | Sticker maker + watermark. |
| 📊&nbsp; **Sistem Level** | XP, level, limit, profile user. |
| 👑&nbsp; **Owner Tools** | Broadcast, reset data, maintenance. |

## 💡&nbsp; Contoh Penggunaan

<br>

### ▶️&nbsp; Membuat Sticker

Kirim gambar dengan caption:

```
.sticker
.brat
.s
.bratvid
```

<br>

### ▶️&nbsp; Download Video TikTok

```
.tiktok https://vt.tiktok.com/xxxx
.ttslide
.ttmp3
```

<br>

### ▶️&nbsp; Download Video Instagram

```
.ig https://www.instagram.com/p/xxxx
.ig story
.ig reels
```

<br>

### ▶️&nbsp; Download Lagu

```
.play judul lagu
.play3
.spotifyplay
.spplay
```

<br>

### ▶️&nbsp; Chat AI

```
.ai rekomendasi anime romance
.gpt
.gemini
.erineai
.rine
```

<br>

### ▶️&nbsp; Game & Fun

```
.truth
.dare
.tebakgambar
```

<br>

### ▶️&nbsp; Menampilkan Menu

```
.menu
.menu all
.help
```

🔹&nbsp; Gunakan bot dengan bijak, jangan spam command jika ingin fitur bot awet!

🔹&nbsp; Jangan make fitur kalo ga penting, ingat script ini pake apikey yang ada limitnya! jadi tetap berhemat
